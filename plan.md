🐍 День 1 — Python: следующий уровень

Сегодняшняя тема — модули и разделение кода.

Мы специально начинаем с неё, потому что это следующий логичный шаг после твоего movie_catalog.py + helpers.py.

Ты уже умеешь создавать функции. Теперь научимся правильно раскладывать эти функции по файлам и использовать их друг из друга.

📖 Теория

Допустим, у нас есть:

project/
├── main.py
├── movies.py
└── helpers.py

В helpers.py:

def find_best_movie(movies):
    ...

В main.py мы можем использовать её:

from helpers import find_best_movie

После этого:

best = find_best_movie(movies)
Главное

import позволяет использовать код другого модуля.

Это фундаментальная вещь. Практически любой нормальный Python-проект состоит из множества модулей.

🧠 Алгоритмическая разминка

Сегодня без нового алгоритма.

Хочу проверить уже имеющееся мышление.

Есть:

numbers = [4, 7, 2, 7, 9, 4, 7, 2]

Нужно получить:

{
    4: 2,
    7: 3,
    2: 2,
    9: 1
}

То есть количество каждого числа.

Ограничение:

Не используй Counter.

Сначала попробуй самостоятельно.
