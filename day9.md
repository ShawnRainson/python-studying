Задание 2. super()
Что выведет код?
class Parent:
    def greet(self):
        return "Hello"


class Child(Parent):
    def greet(self):
        return super().greet() + " World"


child = Child()
print(child.greet()) - Hello World

Объясни, какую роль здесь играет super(). - вызов метода родительского класса

Задание 3. Полиморфизм
Что выведет цикл?
class Dog:
    def speak(self):
        return "Woof"


class Cat:
    def speak(self):
        return "Meow"


animals = [Dog(), Cat()]

for animal in animals:
    print(animal.speak()) - Woof, Meow

Почему для выполнения цикла необязательно проверять, является ли объект собакой или кошкой? - потому-что достаточно чтобы у класса был необходимый метод, это полиморфизм

Контрольные вопросы
Ответь своими словами:
1 Чем переопределение метода отличается от наследования метода без изменений? - По сути, переопределение берёт родительский метод и изменяет его функционал, а наследование берёт метод без изменений
2 Почему при собственном __init__ в дочернем классе родительский __init__ не вызывается автоматически? - Потому-что дочерний __init__ может иметь свои атрибуты помимо родительских
3 Что возвращает super() в контексте вызова родительских методов и зачем он нужен? - он позволяет дочернему классу использовать родительские методы, а также позволяет избежать дублирования одних и тех же методов путём вызова его через super()
4 Может ли полиморфизм работать между классами, которые не наследуются друг от друга? - Может
5 В чём разница между наследованием и композицией? Приведи свой пример. - Наследование - дочерний класс является прямым наследником методов родительского. Композиция - Класс связан с другим, но не является его наследником
Aircraft и Wing - композиция
Parent и Child - наследование
6 Почему не всегда полезно создавать наследника только ради повторного использования кода? - Потому-что порой классу не нужны все те методы что есть у другого класса
