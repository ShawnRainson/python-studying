Задание 4

Что произойдёт?

def outer():
    x = 1


    def inner():
        nonlocal x
        x += 4


    inner()
    print(x)


outer()

Почему?

Ответ: Выведет 5 в обоих случаях, так как был применен nonlocal для изменения локальной переменной внешней функции.

🎯 Дополнительный вызов (сенсейский)

В конце ответь одним предложением:

Чем отличается global от nonlocal?

Ответ: global нужен для изменения глобальной переменной внутри функции.
nonlocal для изменения локальной переменной во внешней функции.
