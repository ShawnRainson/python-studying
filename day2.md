Задание 6

Что произойдёт?

def multiply(a, b, c):
    return a * b * c


numbers = [2, 3, 4]


result = multiply(*numbers)


print(result)

Напиши:

1 Что окажется в a, b, c?
Ответ: a = 2, b = 3, c = 4
2 Что выведет программа?
Ответ: их произведение, то есть 24
3 Что именно делает *numbers?
Ответ: распаковывает список, и присваивает его объекты именам a, b, c по порядку.

Задание 7

Что произойдёт здесь?

def introduce(name, age, city):
    print(f"{name}, {age}, {city}")


user = {
    "name": "Alex",
    "age": 25,
    "city": "Berlin"
}


introduce(**user)

Объясни, во что фактически превращается вызов introduce(**user).
Ответ: словарь user, распаковывается и параметрам функции, присваиваются ключи и значения словаря по порядку.

Задание 8 — найди ошибку 🐛

Что не так?

def greet(name, age):
    print(name, age)


data = ["Alex", 25, "Berlin"]


greet(*data)

Получится ли выполнить этот код?

Если нет — почему?

Ответ: Функция принимает только два параметра, а мы распаковываем список с тремя параметрами, поэтому будет ошибка.
